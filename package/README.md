# GTFO.Glaive

*(Listed on Thunderstore as `GtfoGlaive` — package names there can't contain a period.)*

Adds the **Glaive**: a long razor-edged blade on a spear shaft, brought down overhead like a
splitting maul. Pick it in the melee slot of the loadout screen like any other melee weapon.

| | Spear | Sledgehammer | **Glaive** |
|---|---|---|---|
| Model | MACO Drillhead / IsoCo Stinger | Kovac Sledgehammer etc. | **IsoCo Stinger** |
| Swing | forward thrust | overhead | **overhead** (hammer animations + sounds) |
| Light / charged damage | 2 / 17.5 | 3 / 20 | **3 / 20** |
| Reach | 3.2 | 1.8 | **3.2** |
| Hit width | 0.15 | 0.3 | **0.3** |
| Hits several enemies per swing | yes | no | **yes** |

Every other stat (stamina costs, stagger, precision bonuses, etc.) starts from the spear's.

**Multiplayer:** everyone in the lobby needs this mod - weapons sync between players by an id that
only exists for players who have it installed.

**Compatible with GTFO.EZ.** GTFO.EZ's melee tuning applies to Bat, Hammer, Knife and Spear by
name, so it leaves the Glaive's own stats alone; the two mods don't touch each other's data.

## Changelog
